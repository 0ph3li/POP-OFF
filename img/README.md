# Photos

Every photo on the site is a slot. Put a file with the name below in its folder and it shows up; the extension doesn't matter (jpg, png or webp all work). Until then, a placeholder in the photo's own tone describes what goes there. In the browser console, `popoff.missing()` lists anything still missing.

The big originals live in `_originals` inside each folder; the site uses compressed copies.
